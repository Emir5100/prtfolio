# 个人作品集网站

基于 React + Vite 的个人作品集基础版本，内容依据简历和 2026 平面设计作品集整理。

## 本地运行

```bash
pnpm install
pnpm dev
```

构建生产版本：

```bash
pnpm build
```

## 已完成内容

- 全屏视频 Hero、第二屏后悬浮的磨砂导航与合作按钮
- 个人介绍、联系方式、项目数据和经历时间线
- 8 个精选项目案例组、53 个作品画面与项目详情弹层
- 4 项设计能力与工具栈
- 全屏联系方式收尾页
- 桌面端优先，同时包含基础响应式适配
- 桌面设计基准为 1920 × 1080，内容安全版心约为 1700 × 960
- 使用 AI 美化后的全彩编辑人像（保留本人身份特征）
- GSAP + ScrollTrigger 开场动画、标题切入、卡片 stagger、图片 reveal 与滚动视差
- 持续跟随鼠标位置的卡片边缘发光和颗粒渐变动态色带

Hero 使用用户提供视频的 30 秒网页压缩片段；项目图片从用户提供的作品集 PDF 中提取，个人照片以用户提供照片为身份参考进行 AI 编辑美化。
